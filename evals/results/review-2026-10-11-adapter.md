## 行为核对

### 中性系统提示

### 完整 stdin 与参数隔离

- `evals/adapter-pi-example.mjs:25` 收集完整 stdin；提示不在 argv 内，不经过 shell。
- `evals/adapter-pi-example.mjs:37` 为子进程启用 stdin 管道，末尾先注册输入错误监听，再调用 `child.stdin.end(prompt)`，显式发送 EOF。
- `--model` 保留传入的 provider/model 字符串；实际 argv 测试确认完整提示仅在 stdin 中，换行和中文保持一致。
- 超过 150,000 字符的提示往返一致，未触发单参数长度限制；输入提前关闭时返回非零状态、中文 EPIPE 诊断和空 stdout。
- 实际 argv 锁住全部八个要求的隔离参数：`--no-extensions`、`--no-tools`、`--no-mcp`、`--no-context-files`、`--no-prompt-templates`、`--no-skills`、`--no-session`、`--offline`。
- 未为测试开放工具执行权限。上述结论确认参数实际传递，不将 fake pi 的参数检查夸大为真实 CLI 已落实所有隔离效果。

### JSONL、EOF 与 Unicode

- stdout 使用严格流式 UTF-8 解码，跨 chunk 多字节字符保持完整，EOF 调用解码收尾；无效或截断 UTF-8 均失败。
- EOF 对剩余缓冲调用 JSON 解析：完整且无末尾 LF 的最终事件成功，损坏或不完整 JSON 失败，不静默丢弃。
- 最终助手消息的文本部分同时检查字符串类型及 `isWellFormed()`；JSON 转义的孤立高、低代理项均失败，不输出替换字符或部分文本。
- 只在子进程正常关闭、没有已记录错误且存在非空最终文本后写 stdout；日志和思考部分不混入正文。
- 无最终事件、空最终文本、损坏最终结构、已有有效文本后的坏事件或空最终消息均不能成功；模型 `errorMessage`、ENOENT、非零退出和信号终止均失败。

## 剩余风险与未检查项

1. 本轮未运行真实 pi 或模型。真实 CLI 是否读取非 TTY stdin、如何落实隔离 flags、如何生成协议事件，仍须以最终版本真实运行证据核对；旧 41 例报告保留当时上下文，不在本记录中覆盖或升级为终版证明。
2. 八个隔离参数不是操作系统沙箱。适配器仍继承宿主环境，模型提供方、认证及其他设置可能影响行为。`--offline` 不应被解释为禁止模型网络请求；`--no-session` 也不是模型提供方不保留输入的保证。本轮只验证实际参数，没有实测这些外部效果。
3. 适配器本身没有输入、输出容量上限或超时；失败终止仅发送默认 SIGTERM，再等待子进程 `close`。忽略终止信号或不释放管道的子进程仍可能拖延收尾。外层评测器的约束不能当成此脚本独立运行或子孙进程清理的保证。
4. 完整提示传递验证覆盖有效 UTF-8 文本，不覆盖任意输入字节。输入侧使用 `Buffer.toString('utf8')`，直接给脚本损坏 UTF-8 时会发生替换；本记录的 Unicode 失败闭合结论针对模型 stdout 及最终文本。
5. JSONL 校验覆盖本记录列出的协议异常，不是全部 pi 事件的完整 schema 验证；其他有效类型的生命周期事件可以被忽略，空白行也被忽略。未来协议变化仍需更新兼容性证据。
6. 未跑整套回归、安装副本或全仓编码检查；27 项通过不等价于完整 CI。未修改任何模型评测报告，也未审查其语义结论。
